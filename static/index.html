🚀 My WebServer

● 服务器运行中 — Phase 2: HTTP 静态文件服务器

这是一个练习项目，正在逐步构建一个高并发 C++ Web 服务器。

当前阶段：HTTP/1.1 静态文件服务器

部署平台：NVIDIA Jetson Xavier NX (ARM64)

已实现功能

  • HTTP/1.1 协议解析（状态机：请求行 → 头部 → 正文）
  • mmap 零拷贝文件映射
  • writev 分散/聚集 I/O
  • 长连接 keep-alive 支持
  • MIME 类型自动识别
  • 错误页面（400 / 403 / 404 / 500）
  • LT / ET 触发模式切换

测试命令

# 基本请求
curl -v http://localhost:9006/

# 查看响应头（MIME 类型、keep-alive）
curl -v http://localhost:9006/index.html

# 404 测试
curl -v http://localhost:9006/nonexistent.html

# keep-alive 测试
curl -v -H "Connection: keep-alive" http://localhost:9006/
