🚀 My WebServer

● 服务器运行中 — Phase 4: 生产级高并发 HTTP 服务器

从零构建的 C++ 高并发 Web 服务器，复刻 TinyWebServer。

部署平台：NVIDIA Jetson Xavier NX (ARM64)

技术栈：epoll + 线程池 + 非阻塞 IO + 定时器 + 异步日志 + MySQL

已实现功能

  • epoll I/O 多路复用（LT / ET / EPOLLONESHOT）
  • HTTP/1.1 协议解析（主-从状态机）
  • mmap 零拷贝 + writev 分散/聚集 I/O
  • 线程池（生产者-消费者 + Reactor/Proactor）
  • 长连接 keep-alive 支持
  • MIME 类型自动识别（16 种）
  • 错误页面（400 / 403 / 404 / 500）
  • 定时器：有序双向链表 + 15s 超时断开 + SIGALRM 心跳
  • 异步日志：阻塞队列 + 后台线程 + 按天/按行滚动
  • 统一事件源：socketpair 信号桥接
  • 数据库连接池：RAII + 单例 + 信号量控制
  • CGI 登录/注册：MySQL 后端 + 内存缓存

测试命令

# 基本请求
curl -v http://localhost:9006/

# 查看响应头（MIME 类型、keep-alive）
curl -v http://localhost:9006/index.html

# 404 测试
curl -v http://localhost:9006/nonexistent.html

# 压力测试（需要安装 wrk）
wrk -t4 -c100 -d10s http://localhost:9006/

# 并发连接测试
ab -n 10000 -c 100 http://localhost:9006/
